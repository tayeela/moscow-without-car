# Москва без машины

Интерактивная карта о том, как передвигаться по Москве без личного автомобиля:
метро, велоинфраструктура, веломаршруты — и парки, до которых на всём этом можно доехать.

**Карта: https://tayeela.github.io/moscow-without-car/**

Репозиторий: https://github.com/tayeela/moscow-without-car

## Слои карты

| Слой | Способ изображения |
|---|---|
| Число велопарковок по районам | картограмма |
| Входы станций метро | кластеризация маркеров |
| Велопарковки | тепловая карта |
| Велодорожки | линии |
| Веломаршруты («Вело1», «Яуза», «Зелёное кольцо» и др.) | линии |
| Парки и природные территории от 5 га | полигоны |

Инструменты: управление слоями, полноэкранный режим, мини-карта.

## Данные

- [Портал открытых данных Правительства Москвы](https://data.mos.ru), загрузка через официальный API:
  - № 624 — Входы и выходы вестибюлей станций метро
  - № 916 — Велосипедные парковки
  - № 897 — Дорожки велосипедные
- [OpenStreetMap](https://www.openstreetmap.org):
  - веломаршруты (Overpass API, `route=bicycle`)
  - парки и природные территории (`leisure=park`, ООПТ)
  - границы районов (Overpass + геокодер Nominatim через OSMnx)
